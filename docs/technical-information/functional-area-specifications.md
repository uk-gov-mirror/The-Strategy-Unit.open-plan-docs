# Functional Area Specifications

The reference file that links activity classifications, assumptions, conversion archetypes and capacity outputs for each functional area.

Each functional area defines one or more calculation subgroups, with their associated classifications, assumptions and capacity outputs. Where applicable, it also specifies exclusions and workload deductions involving other functional areas.
